# WANDER — Find Your Somewhere 🌍

A responsive travel discovery website built with plain HTML, CSS, and JavaScript.

## Run it in VS Code
1. Extract `WANDER-Travel-Website.zip`.
2. Open the `wander_travel_website` folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension and click **Go Live**.

## Features
- Responsive desktop and mobile navigation
- Cinematic travel photography and editorial layout
- Search destinations by name
- Filter destinations by travel mood/category
- Destination cards with sample prices and ratings
- Save-heart interaction on destination cards
- Newsletter form with email validation and a success state
- Reduced-motion accessibility support

## Notes
- Destination prices and ratings are sample presentation content, not live offers.
- Images and fonts load from Unsplash and Google Fonts, so an internet connection is needed for those assets.
- The newsletter is a front-end demo; it does not send or store email addresses. Connect a newsletter provider or backend before using it in production.
